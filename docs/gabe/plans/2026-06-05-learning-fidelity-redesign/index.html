Summary

Make Archie's simulation, scoring, and lesson-loop teach real, transferable system design instead of rewarding harness-gaming. A full A→D epic distilled from a 3-perspective roast (architecture-educator, simulation/domain-expert, first-time-learner; 22 gaps).

Guiding principle (D74): score on behavior, not block-presence. The recurring disease is the rubric rewarding “the right blocks on the canvas” over “the blocks doing their job under load.” The reference builder's own exploits (traffic-free aux leaves, “add cache always wins”, over-provision one tier) are the canary — re-roast after each phase to confirm they shrink.

Phase 2 — Core engine fidelity enterprise

Honest physics. High re-calibration ripple — fixes the two most-inverted intuitions.

  • ED1/EN1 — end-to-end latency = SUM along the served path (+ inter-node RTT); cache hits short-circuit; worst-hop kept only as the overload term.
  • ED4/LX4 — replace flat-then-linear latencyUnderLoad with a queueing curve (latency → ∞ as ρ→1) so headroom is real and the live gauge teaches.
  • EN2 — add a concurrency/queue model (per-variant concurrency limit; latency↔queue-depth via Little's law) so saturation = latency AND connection rejection.

Phase 3 — Resilience as a real subject enterprise

Make resilience both possible and rewarded. Do the three together — they reinforce.

  • ED2 — AZ attribute per node; az_outage removes a fraction (1/AZ) of a category so spreading replicas/nodes genuinely survives.
  • EN3 — cascading failure: shed propagates upstream as timeouts + retry amplification (the real thundering-herd cause).
  • EN7 — observability earns its keep: faster detect → earlier circuit-break → smaller blast radius (replaces the magic 33% constant).
  • + restore no-SPOF redundancy to scoring (topology-star contributor or resilience metric) — reverses the D72 demotion now that redundancy is mechanically meaningful.
simulationEngine.ts · topologyChecker.ts · rubricScorer.ts · challengeTypes.ts

Sequence: needs EN6 (cyclic-flow solve, Phase 4) first — pull it forward or do it before EN3 retries. Exit: re-tune outage challenges (chaos-day, async-backbone, heat-death, fortress, zone-*) · regenerate · harness 3★ all 57.

Phase 4 — New dimensions scale

The 10x-breadth tier. À-la-carte sub-slices — each additive/defaulted so existing challenges score identically.

  • ED5 — dynamic cache hit-ratio (variant ceiling × cacheable-fraction × (1−write-pressure); search/periodic lower it).
  • ED9 — autoscaling (replicas track load; cost integrates over the curve) so bursts reward elasticity, not peak-provisioning.
  • EN5 — usage-based cost (per-request + per-GB cross-region transfer) so cost challenges teach egress-dominated bills.
  • ED6/EN4/ED8 — the big one: multi-region latency + replication lag/staleness + a NEW consistency/CAP scoring dimension + challenge family.
  • EN6 — fixed-point cyclic-flow solve (closes PENDING D7, unblocks EN3 retries).
